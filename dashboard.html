宿題・小テスト

最大4セクション。文法・語法演習／単語学習と同じUIで設定し、保存時に JSON 化してシートへ保存します。各セクションで「1問あたりの配点」を指定できます（小テストの得点計算に使用）。配布対象は class + attribute1～5（空＝制限なし）。

挑戦回数に上限はありません。例: 3 → 制限時間・合格ラインを3回クリアで達成（達成まではローカル記録のみ）。

文法・語法演習／単語学習と同じ操作感で設定します。保存時に自動で JSON 化されシートに記録されます。

☑は1件だけ選んで「同じ設定で新しい課題を作成開始」（過去の出題をプリセット化）。複数チェックで「削除」できます。

課題点検票（名簿転記）

whitelist の学年・組・番号・attribute1～5 で対象メンバーを絞り、該当者だけの点検用名簿を作ります（空欄＝その区分は制限なし。番号は 1-20 のような範囲も可。属性は列同士 AND、同一列はカンマ区切り OR）。既存ブックIDを保存した時点で見出し・名簿・課題列を整備します。提出結果の追記は時間トリガー（10分ごと）です。

whitelist の grade が学籍番号などのIDのとき、数字だけを左から数えた桁。例: ID 24103 で 2桁目が学年なら 2。2桁にまたがるなら 2-3。
