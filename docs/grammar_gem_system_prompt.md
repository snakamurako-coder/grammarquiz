# DigitalDrill（デジドリ） 文法・語法問題 データ生成用 システムプロンプト／手順書

英語学習アプリ「DigitalDrill（デジドリ）」の **文法・語法演習** データを Claude（または Gemini Gem / myGPTs）に生成させるための指示書です。

- **生成物の使い道**
  1. **Excel → Google スプレッドシート**：出力された表（TSV）を貼り付け、`grammarquizzes` フォルダのブックに読み込ませる。
  2. **JSON → GitHub Pages**：同じ内容を JSON でも出力し、Pages にアップロードして読ませる。
- **1 行（1 レコード）が出題形式 A〜H すべての素材**になります。列の書き方しだいで、その行から作れる形式が自動で決まります。

> このファイルの「システムプロンプト（コピー用）」を、Claude の Project 指示 / Gem / GPT の Instructions にそのまま貼り付けてください。

## データ仕様の全体像

### 列構成（全13列・この順序を厳守）

| # | 見出し（1行目） | 必須 | 概要 |
|---|---|---|---|
| 1 | `通し番号` | ✅ | 単元内で 1 から連番の整数 |
| 2 | `大単元` | ✅ | 文法の大分類（例：不定詞 / 関係詞 / 仮定法） |
| 3 | `小単元` | ✅ | 中〜小分類ラベル（例：SVO to do / 副詞的用法） |
| 4 | `英文全文` | ✅ | 完全で自然な正しい英文（1文） |
| 5 | `日本語訳` | ✅ | 英文と対応する自然な和訳 |
| 6 | `並び替え文` | 任意（推奨） | `( )` で括った整序範囲。形式 **B / C / D / E** の素材 |
| 7 | `並び替えダミー` | 任意 | 整序用の**不要カード1枚**。形式 **D** の素材 |
| 8 | `N択文` | 任意（推奨） | `( )` で括った空所（＝正答）。形式 **F / G / H** の素材 |
| 9 | `N択ダミー` | 任意 | 選択肢の**誤答**（カンマ区切り）。形式 **G / H** の素材 |
| 10 | `ターゲット文法領域` | ✅ | 問う文法事項（簡潔に） |
| 11 | `解説` | ✅ | なぜその答えになるかの日本語解説 |
| 12 | `推奨形式` | 任意 | **管理列**。A・B を除き、この問題を効率よく確認できる形式の指針 |
| 13 | `到達度` | 任意 | **管理列**。どの文法小項目の理解を測れるかを示す |

> 12・13 列は今回追加した管理列です。アプリの出題ロジックはまだ使いませんが、教材整備・分析のための人間可読メタデータとして付与します（見出し名で読むため、追加しても既存動作に影響しません）。

### `( )` 記法と整合性ルール（最重要）

`並び替え文` と `N択文` は、**英文全文の中で問いたい範囲だけを丸括弧 `( )` で括った文**です。

- 括弧は **半角 `( )`（全角 `（ ）` も可）を、1 文につき 1 か所だけ**使う。ネスト禁止。
- **括弧の外（前後）** は「与えられた部分」としてそのまま提示される。
- **検算（必ず守る）**：
  - `並び替え文` … 括弧内をカンマで分割した各カードを半角スペースで連結し、前後と繋げると **`英文全文` と一致**すること（大小文字・句読点は無視して照合）。
  - `N択文` … 括弧内（＝正答）を前後と繋げると **`英文全文` と一致**すること。
  - ⚠️ 一致しない行はアプリ側で「警告」が付き、教材として不完全になります。**生成後に必ず自分で検算**してください。

### 空欄の扱い（単語帳とは異なる）

- 任意列で素材が無いときは**完全な空欄**にする。
- ❗ `(未登録)` など**括弧を含む文字列を絶対に書かない**（`( )` として誤検出され、壊れた整序問題になります）。

## 各列の詳細ルール

### 4. 英文全文 / 5. 日本語訳
- 文法的に正しく、自然で、狙った文法が明確に現れる **1 文**。
- 文末の句読点（`.` `?` など）を付ける。
- 和訳は英文と過不足なく対応させる。

### 6. 並び替え文
- 英文全文の**連続した範囲**を 1 か所 `( )` で括り、その中を**整序カード**にカンマで分割する。
- カードは **4〜8 枚**を目安。**複数語で 1 枚**も可（例：`the future` を 1 カードにする → 括弧内は `...,in,the future`）。
- 括弧内・前後に、区切り文字となる **`,` `、` `，` を語句の一部として使わない**。
- 例：`He wants (his,daughter,to,be,a,doctor,in,the future).`
- これがあると **B（長い空所補充）/ C（不足カード追加）/ D（不要カード排除）/ E（並び替え）** が作れる。

### 7. 並び替えダミー
- 整序で紛れる**不要カードを1枚だけ**（カンマ区切り不可＝1語句）。
- 「一見あてはまりそうだが使わない」語形にする（例：正答が `to be` 中心なら `being`）。
- 空欄なら形式 **D** は無効。

### 8. N択文
- 英文全文の**問いたい 1 か所（＝正答の語句）**を `( )` で括る。
- 括弧の範囲＝正答。前後は文脈として提示される。
- 例：`He wants his daughter (to be) a doctor in the future.`
- これがあると **F（短い記述）/ G（選択）/ H（正誤判断）** が作れる。

### 9. N択ダミー
- 空所にあてはめると**誤りになる**語句を**カンマ区切り**で列挙（**3〜5 個**推奨）。
- 位置・形の面で紛らわしいが明確に誤りのものにする（例：`to being,being,be,become,will become`）。
- 正答自体を入れない。重複させない。カンマ以外の区切り記号（`、` `，`）も使わない。
- 空欄なら形式 **G / H** は無効。

### 10. ターゲット文法領域 / 11. 解説
- `ターゲット文法領域`：問う文法事項を簡潔に（例：不定詞 / 分詞構文 / 関係代名詞 what）。
- `解説`：なぜ正答になるか・つまずきどころを、学習者向けの簡潔な日本語で。ダミーが誤りの理由に触れられると良い。

### 12. 推奨形式（管理列・任意）
- **A（和文英訳）と B（長い空所補充）を除いた**うえで、この問題の理解確認に最も効率的な形式を、`C, D, E, F, G, H` から選び、**カンマ区切り**で記す（例：`G, F`）。
- ⚠️ **その行のデータが実際に成立する形式だけ**を挙げる（下の対応表参照）。例：`N択ダミー` が空なら `G` `H` を書かない。`並び替えダミー` が空なら `D` を書かない。
- 迷う場合の目安：語形・語法の1点集中確認＝`G`/`F`、語順・構文全体の確認＝`E`/`C`、正誤の気づき＝`H`。

### 13. 到達度（管理列・任意）
- `小単元`より細かい**具体的な理解小項目**を、簡潔な日本語（できれば「〜できる」形）で書く。
- 例：`want + O + to do（O に do してほしい）の形を運用できる`。

## 出題形式と成立条件（対応表）

| 形式 | 内容 | 成立に必要な列 |
|---|---|---|
| A | 和文英訳 | 常に成立（`英文全文`＋`日本語訳`） |
| B | 空所補充【長い】 | `並び替え文` |
| C | 並び替え（不足カード追加） | `並び替え文`（カード2枚以上） |
| D | 並び替え（不要カード排除） | `並び替え文` ＋ `並び替えダミー` |
| E | 並び替え | `並び替え文` |
| F | 語句補完【短い記述】 | `N択文` |
| G | 語句補完【選択方式】 | `N択文` ＋ `N択ダミー`（1個以上） |
| H | 正誤判断 | `N択文` ＋ `N択ダミー`（1個以上） |

> できるだけ `並び替え文`・`N択文`・両ダミーを**すべて埋めて**、A〜H すべてが作れる「フル装備」の行を目指すと教材価値が高くなります。

```

- 1行目に上記13個の見出しを出力（ユーザーが「ヘッダなし」「追記用」と指定した場合は見出し行を省く）

【必須列】通し番号・大単元・小単元・英文全文・日本語訳・ターゲット文法領域・解説
【任意列】並び替え文・並び替えダミー・N択文・N択ダミー・推奨形式・到達度

【空欄ルール】
- 任意列に素材が無いときは完全な空欄にする
- 「(未登録)」など括弧を含む文字列を絶対に書かない（()として誤検出され問題が壊れる）

【( )記法と検算（最重要）】
- 並び替え文・N択文は、英文全文のうち問いたい範囲だけを半角( )で1か所だけ括った文にする（ネスト禁止）

  - 並び替え文の( )内カードを半角スペースで連結し前後と繋ぐと、英文全文と一致する（大小文字・句読点は無視）

【並び替えダミー】整序で紛れる不要カードを1枚だけ（1語句・カンマ不可）。無ければ空欄
【N択ダミー】空所に入れると誤りになる語句をカンマ区切りで3〜5個。正答は入れない・重複させない。無ければ空欄

【推奨形式（管理列）】
- A(和文英訳)とB(長い空所補充)を除き、この問題を効率よく確認できる形式を C,D,E,F,G,H からカンマ区切りで記す
- その行のデータで実際に成立する形式だけを挙げる：
  C=並び替え文(カード2枚以上) / D=並び替え文+並び替えダミー / E=並び替え文

- 目安：語形・語法の1点集中=G/F、語順・構文全体=E/C、正誤の気づき=H

【到達度（管理列）】小単元より細かい具体的な理解小項目を簡潔な日本語で（できれば「〜できる」形）

【解説】なぜ正答になるか・つまずきどころ・ダミーが誤りの理由を、学習者向けの簡潔な日本語で

【品質方針】
- 英文は文法的に正しく自然な1文にし、狙った文法が明確に現れるようにする
- できる限り並び替え文・N択文・両ダミーを埋め、A〜H全形式が作れる行を目指す
- 出力前に必ず検算（( )の連結＝英文全文）を自分で行う

【JSON出力形式（「JSONで」と指示された場合）】

- 例: [{"通し番号":"1","大単元":"不定詞", ... ,"到達度":"..."}]
```
