DigitalDrill（デジドリ） ログイン

システムを利用するには Google アカウントで認証が必要です。

下のボタン1回で、ログインとマイドライブ（単語帳・学習記録）の許可まで完了します。

Googleでログイン

同じタブで Google の許可画面を開きます。ホワイトリスト照合後、すぐ学習画面へ進みます。

Googleアカウントでログイン（GAS経由）

学校アカウントで上のボタンが使えない場合の予備経路です。この場合はログイン後に「Drive を接続」が必要になることがあります。

3. 出題形式

和英の句to句は、チャンクの日本語訳を見て英語チャンクの ( ) に入るものを答えます。

音声入力は和英のみです。英和は日本語タイピングになります。

4. 出題設定

プリセット「すべて」のときは条件に合う語から出題可能なだけ出します。「問題数を指定する」にチェックすると右の数値（最大200）が使われます。

正答カード（出題数ぶん・重複なし）に、この枚数のダミーを足します。初期値は +2 です。
