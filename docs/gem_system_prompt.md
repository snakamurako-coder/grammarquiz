# DigitalDrill（デジドリ） 単語帳データ生成用 システムプロンプト／引き継ぎ書

英語学習アプリ「DigitalDrill（デジドリ）」の **マイ単語帳** に登録する単語データを、Gemini Gem / ChatGPT myGPTs などに生成させるための指示書です。

- **入力**: ユーザーが英単語・熟語のリスト（任意で大区分・中区分・小区分）
- **出力**: 21列 TSV（タブ区切り・ヘッダなし・1語1行）。アプリの「TSV貼り付け」欄にそのまま貼れる
- **正の仕様**: `code.gs` の `VOCAB_HEADERS` / `docs/user-drive.js` の `VOCAB_HEADERS`

> このファイルの「システムプロンプト（コピー用）」を Gem / GPT の Instructions にそのまま貼り付けてください。  
> 列構成を変更したら `code.gs` と本ファイルを **セットで** 更新すること（`.cursor/rules/keep-generator-prompts-in-sync.mdc`）。

\* **列5〜12（意味列）のうち少なくとも1列**に有効な意味が必須。空欄は `(未登録)` に正規化される。

### 空欄の扱い（文法問題とは異なる）

- 未入力・該当なしは **必ず `(未登録)`** と書く（**空欄禁止**）
- 文法問題データでは空欄を使うが、単語帳では `(未登録)` が契約

### `( )` 記法（チャンク・例文）

- **半角 `( )`** を使用（全角も可だが半角推奨）
- **当該語・当該熟語の部分だけ**を括る。括弧は1か所でも複数か所でも可（熟語全体を1か所で括る）
- チャンク訳・例文訳では、当該語に対応する日本語部分も `( )` で括る
- 活用形（複数形・三人称単数・過去形など）を使ってよい

## 2. 品詞別意味の入力ルール（列5〜12）

### 基本

| 語の種類 | 意味を入れる列 | 列5〜11の扱い |
|---|---|---|
| 通常の単語（名詞・動詞など） | 該当品詞の列のみ | 該当しない品詞列は `(未登録)` |
| 熟語・慣用表現（look up, give up） | **列12のみ** | 列5〜11は **すべて `(未登録)`** |
| 間投詞（well, oh, wow） | **列12のみ** | 列5〜11は **すべて `(未登録)`**。列11（その他品詞）には入れない |

### 複数品詞を持つ単語

- 該当する品詞の列にそれぞれ意味を入れる（例：`well` は名詞・動詞・形容詞・副詞＋間投詞を列12）
- 名詞と動詞で意味が異なる場合は両方に入れる（例：`book`＝本 / 予約する）
- 形容詞・副詞が同形の場合は両方に入れる（例：`fast`＝速い / 速く）

### 英文による定義（列17）

- **最もよく使われる品詞**の意味を、簡潔な英語で英英辞典風に定義
- 複数品詞がある場合は代表品詞を1つ選ぶ

## 4. パターン別の書き方ガイド

### 多品詞＋間投詞（well）

- 名詞・動詞・形容詞・副詞はそれぞれの列に入れる
- 間投詞「ええと・さて」は **列12** に入れる（列11には入れない）
- 例文では異なる品詞の用法を示す（副詞：She sings (well). / 名詞：The water in the (well) is clean.）
- メモで品詞ごとの注意点を簡潔に書く

### 名詞＋動詞（book, water, run）

- 名詞・動詞の意味をそれぞれの列に入れる
- 名詞形と動詞形が同じ場合（run）も両列に入れる
- チャンクは代表的な用法を1つ、例文は学習者にとって自然な文を1つ

### 形容詞のみ（happy）

- 列7（形容詞）のみに意味。列5・6・8〜12は `(未登録)`
- 派生語（happily, happiness）を列16に入れる

### 形容詞＋副詞同形（fast）

- 列7・列8の両方に意味を入れる
- メモで「fastly は存在しない」など学習上の注意を書く

### 接続詞・前置詞のみ（because, under）

- 列10（接続詞）または列9（前置詞）のみに意味
- チャンクで because of / under the table など代表的な句を示す

### 熟語（look up, give up）

- **列12のみ**に意味。列5〜11は **すべて `(未登録)`**
- 熟語全体を `( )` で括る（例：`(look up)`, `(give up)`）
- メモに構文上の注意（代名詞の位置など）を書く

- ヘッダ行は出力しない
- 1語につき1行

## 7. 使い方

### Gem / GPT のセットアップ

1. Gemini Gem または ChatGPT のカスタムGPTを作成
2. 上記「システムプロンプト（コピー用）」を Instructions に貼り付け
3. 必要に応じて本ファイルの「サンプル10語」TSVを Knowledge に追加（品質向上用）

### DigitalDrill への取り込み

1. Gem に単語リストを入力
2. 出力された TSV をコピー
3. DigitalDrill の「単語登録」画面 → TSV貼り付け欄にペースト
4. 「TSVを解析してプレビュー」→ 内容確認 → 「プレビューを一括登録」

### ユーザー向け入力例

```
次の単語を登録用TSVで出力して:
- 大区分: 通常ステージ / 中区分: Stage1 / 小区分: Lesson1
- 単語: run, happy, look up
```
